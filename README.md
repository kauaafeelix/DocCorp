# 🏢 DocCorp

> Projeto acadêmico criado exclusivamente para fins de documentação de sistemas.

---

## 🗂️ Sobre

O **DocCorp** é um projeto desenvolvido com o objetivo de **documentar sistemas**, servindo como exemplo prático de como estruturar, descrever e apresentar sistemas de forma clara e organizada. Não se trata de uma aplicação funcional, mas sim de um exercício de documentação técnica.

---


## 🛠️ Tecnologias utilizadas

| Tecnologia | Função |
|---|---|
| 🌐 HTML5 | Estrutura das páginas |
| 🎨 CSS3 | Estilização e layout |
| ⚡ JavaScript | Interatividade |

---

## 🚀 Como executar

```bash
# Clone o repositório
git clone https://github.com/kauaafeelix/DocCorp.git

# Acesse a pasta
cd DocCorp
```

> Abra o arquivo `index.html` diretamente no navegador — sem necessidade de servidor! 🌐
