Guia rápido

  • Componentes: usar componentes principais (Buttons, Inputs, Cards) para consistência.
  • Grid e espaçamento: seguir o sistema de espaçamento do design token do projeto.
  • Tipografia: nomes e tamanhos estão no arquivo "Typography".
  • Ícones e imagens: exportar em PNG/WebP para imagens e SVG para ícones quando possível.

Export e convenções

  • Nomes de camadas: usar nomes descritivos (btn-primary, card-project).
  • Exportar imagens em 2x quando for necessário para telas de alta densidade.
  • SVGs: limpar metadados antes de usar no código.
